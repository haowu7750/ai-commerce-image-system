# 角色工作区前端

这是 AI 电商运营助手系统的 Next.js 前端，已经接入本地 FastAPI、JWT 会话、数据库持久化和服务端 RBAC。

## 已实现

- 登录：开发环境可选择运营、美工、管理员体验账号，也支持邮箱密码登录；演示身份同样由后端签发真实 JWT。
- 运营：工作台、项目创建、商品事实卡保存与确认、产品参考图上传、内容多版本与定稿、美工任务派发与验收、成果汇总导出。
- 美工：只查看分配给自己的任务，更新状态、反馈缺资料、上传多个设计版本。
- 管理员：创建和停用账号、分配角色、维护 Prompt/合规/ERP 元数据版本、查看审计日志。
- AI 生图：两个前置门禁和七阶段后端状态机，默认使用 Mock Provider；高风险和质检失败不能确认。
- 所有关键写操作均经过后端角色检查，管理员不会自动获得运营确认权。

## 安全边界

- 默认不调用付费图片 API，页面会显示实际 Provider。
- 不自动发布，不自动写回 ERP。
- 浏览器上传的本地演示图片以 data URL 存入本地数据库，单文件限制 1.2 MB；生产部署应替换为对象存储。
- 管理页面不得保存 API Key 或密码，只保存非敏感配置元数据。

## 本地运行与验证

从项目根目录双击 `Start-System.cmd`，前端固定使用 `http://127.0.0.1:3100`，后端固定使用 `http://127.0.0.1:8100`。

前端分项验证：

```powershell
pnpm --dir frontend run typecheck
pnpm --dir frontend test
pnpm --dir frontend run build
```
