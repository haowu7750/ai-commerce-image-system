# 阶段 1 需求追踪矩阵

> 文档类型：阶段 0 开发契约  
> 日期：2026-08-10  
> 阶段 1 名称：基础框架、权限与生图工作流内核  
> 当前状态：仅契约完成，代码与测试均待实现  

## 1. 阶段 1 目标与边界

阶段 1 建立可本地启动的前后端、数据库、三角色权限、生图数据骨架、状态迁移内核、Provider 协议、确定性 Mock 和自动化门禁测试。阶段 1 不以真实中转站成功调用为完成条件，也不宣称七阶段业务 UI 已完整交付。

| 需求编号 | 阶段 1 约束 | 验收条件 |
|---|---|---|
| IMG-P1-SCOPE-001 | 阶段 1 必须为七阶段 MVP 工作流建立真实可执行的数据、权限和状态基础，不做静态占位页。 | 至少可通过 API + Mock 从 `draft` 推进到 `product_type_ready`，并查询持久化记录和审计事件。 |
| IMG-P1-SCOPE-002 | 文本、视觉和质量语义检查只使用 Mock；图像生成默认使用 Mock，Relay 仅完成接口、允许列表和安全配置边界。 | 禁网自动化测试通过；未配置 Relay Token 时系统仍可启动并运行 Mock，不显示“真实生图已接通”。 |
| IMG-P1-SCOPE-003 | 阶段 1 不实现自动发布、ERP 图片写回、无人确认最终化或非 `gpt-image-2` 路由。 | 路由/API 扫描及事件断言表明不存在上述副作用；非允许模型测试通过。 |
