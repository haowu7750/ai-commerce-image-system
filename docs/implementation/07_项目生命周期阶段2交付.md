# 项目生命周期阶段 2 交付记录

## 对应需求

- `REQ-M02-06`：项目支持归档和恢复，删除不丢失历史数据。
- 阶段 2 验收项：运营可新建、归档和恢复项目。
- 权限边界：运营管理自己的项目；管理员仅查看和恢复已删除项目；美工无项目管理权限。

## 已实现

- 新建项目默认进入 `draft`，显示在“草稿箱”。
- 运营显式开始项目后进入 `in_progress`。
- 商品卡已确认、最终标题已确认、无未完成美工任务且无未处理生图合规风险时，运营可标记 `completed`。
- 已完成项目只读；运营可重新开启并回到 `in_progress`。
- 删除为软删除，内部兼容状态为 `archived`，界面统一显示“已删除”。
- `project_deletion_records` 保存删除人、原因、时间、删除前状态及恢复记录。
- 恢复回到删除前状态；旧的无删除记录项目保守恢复到草稿。
- 存在未完成美工任务时禁止删除。
- 管理员可查看全部已删除项目并执行紧急恢复，但不能替代运营完成业务确认。
- 美工无法访问项目列表、已删除项目或生命周期写接口。

## API 变化

- `GET /api/v1/projects?bucket=draft|in_progress|completed|deleted|all`
- `POST /api/v1/projects/{id}/start`
- `POST /api/v1/projects/{id}/complete`
- `POST /api/v1/projects/{id}/reopen`
- `POST /api/v1/projects/{id}/delete`
- `POST /api/v1/projects/{id}/restore`
- `GET /api/v1/admin/deleted-projects`
- `POST /api/v1/admin/deleted-projects/{id}/restore`

普通业务 API 不提供物理删除项目的路径。

## 手工验收

1. 运营新建项目，确认项目出现在“草稿箱”。
2. 点击“开始项目”，确认进入“进行中”。
3. 不满足结果门禁时点击“标记完成”，确认显示明确阻断项。
4. 满足门禁后完成项目，确认详情为只读；点击“重新开启”后恢复编辑。
5. 删除时填写原因并二次确认，确认项目进入“已删除”且显示原因和删除前状态。
6. 分别由运营和管理员恢复，确认项目回到删除前状态。
7. 使用美工账号确认没有项目中心和已删除项目入口。

## 剩余边界

- MVP 不提供永久删除。
- 项目完成门禁当前覆盖商品卡、最终标题、美工任务和生图风险；SKU、真实 ERP 写回与平台发布仍不属于本阶段完成条件。
